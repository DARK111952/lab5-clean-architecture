# Політика гілок

| Гілка        | Призначення                                                   |
|--------------|---------------------------------------------------------------|
| `main`       | стабільний код; потрапляє лише через merge з `develop`, має теги |
| `develop`    | інтеграційна гілка, в неї зливаються всі `feature/*`          |
| `feature/*`  | гілки під конкретні задачі (по одній на архітектурний шар)    |

Правила:

1. Гілки `feature/*` створюються від `develop`.
2. Злиття в `develop` — лише через pull request з рев'ю.
3. Повідомлення комітів — за Conventional Commits: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`.
4. Злиття `develop` -> `main` — тільки після перевірки працездатності, з тегом версії.
